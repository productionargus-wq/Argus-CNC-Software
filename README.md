## Overview
Argus CNC Software is a professional CAM (Computer-Aided Manufacturing) and CNC toolpath generation platform engineered for high-precision machining operations.

### Key Capabilities:
- **CAD Solid & Mesh Support**: Native import and processing for STEP (`.step`, `.stp`), STL (`.stl`), and standard solid CAD geometries.
- **Advanced 2.5D & 3D Toolpaths**:
  - Contour Profiling
  - Pocketing (Zigzag, Offset, High-speed clearing)
  - Face Milling
  - Drilling & Tapping
  - 3D Surface Projection
- **Multi-Axis Post-Processors**:
  - Fanuc Controller
  - LinuxCNC
  - GRBL
  - Mach3 / Mach4
  - Heidenhain, Haas, and universal ISO G-code
- **Gesture 3D Navigation**: Intuitive click-and-drag 3D rotation, panning, and zoom.
- **Integrated Toolpath Simulation**: Real-time 3D material removal and cutter verification before sending code to the machine.
- **Silent Background Auto-Updater**: Zero-effort delta updates delivered directly to client installations.

## Getting Started
1. Run `Launch_Argus_CNC_Software.bat` or double-click the **Argus CNC Software** desktop shortcut.
2. Import your 3D CAD model (`File` ➔ `Import`).
3. Create a **Job**, define your stock, and select your machine post-processor (e.g. `Fanuc`).
4. Generate toolpaths, run the 3D **Simulator**, and export your `.nc` G-code via **Post Process (G1)**.
